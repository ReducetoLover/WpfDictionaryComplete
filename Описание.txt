Задание:
Разработать программу для ведения словарей персонала и организаций.
Цели к реализации:

Реализовать удобный графический интерфейс для добавления/удаления/изменения элементов.
Загрузка данных в интерфейс ассинхронно.
Поля словарей должны быть достаточны, у персонала должно быть фото.
Кнопка для добавления 10 организаций со 100 сотрудниками внутри каждой.
Поиск сотрудника по полям.
Ведение текстового лога.

Задачи максимум (доп):

Клиент-серверная организация WCF.
Применение Async/await.
Использовать WPF.

База данных SQLite расположена в папке проекта. Загрузил данные в неё.
Реализовал работу словарей через 2 таблицы.
При нажатии кнопки загрузить данные - заполнится таблица с организациями
При выборе строки с организацией, заполнятся данные таблицы с сотрудниками
Количество сотрудников отображается в поле Count у таблицы организаций
Добавление/удаление осуществляется через кнопки (при добавлении создаётся пустая запись снизу таблицы)
Изменение записывается автоматически в базу данных
У некоторых сотрудников есть фотографии
Работает поиск по всем полям в таблице с сотрудниками
Текстовый лог работает при добавлении/удалении/изменении записей в таблицах


Появляется баг при запуске проекта, когда ломается пространство имён, но всё равно запускается проект. Исправляется перемещением туда-обратно в любую папку MainWindow.xaml
